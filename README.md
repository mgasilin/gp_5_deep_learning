## Бизнес-контекст

Проект решает две связанные задачи для агропромышленной платформы:

1. **Рекомендация культуры** — по агрофону (содержание азота, фосфора, калия и прочего) модель рекомендует оптимальную сельскохозяйственную культуру для посева

2. **Классификация болезней растений** — по фотографии листа модель определяет заболевание среди 38 известных ей. Позволяет пользователям оперативно искать информацию о проблемах на основе снимков с полей.

## Данные

| Задача | Датасет | Ссылка |
|---|---|---|
| Рекомендация культуры | Crop Recommendation Dataset — 2200 примеров, 7 числовых признаков, 22 класса культур | [Kaggle](https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset) |
| Болезни растений | New Plant Diseases Dataset — ~87 000 изображений листьев, 38 классов | [Kaggle](https://www.kaggle.com/datasets/vipoooool/new-plant-diseases-dataset) |

## Логирование экспериментов (MLflow + DagsHub)

Все эксперименты залогированы в DagsHub через MLflow

Организовано два эксперимента:

**`crop_recommendation`** — табличная задача:
- 4 архитектуры полносвязных сетей (NN0, NN1, NN2, ResNet со skip-connections)
- Каждый запуск содержит: параметры архитектуры и обучения, метрики по эпохам (train loss, val accuracy), итоговые метрики на тесте (accuracy, F1), артефакт обученной модели
- Отдельный запуск с данными: сам датасет, обученный `StandardScaler`, `LabelEncoder`, параметры разбиения выборки

**`plant_disease_classification`** — задача на изображениях:
- 5 архитектур: собственная CNN, ResNet-18 (fine-tune и frozen), MobileNet-V3-Small, EfficientNet-B0
- Каждый запуск содержит: параметры архитектуры и обучения, метрики по эпохам (train loss, val accuracy, val F1), итоговые метрики на тесте, артефакт обученной модели
- Отдельный запуск с данными: ссылка на датасет с версией, параметры всех трансформов и аугментаций
